## 7. 第三方 API（手册 p130，PDF133，5.12/5.12.1）

> **5.12 SDK 接口**
> **5.12.1 ZXDoc 接口（第三方 API）**
> 基于 ZXDoc 主功能，提供接口支持外部软件调用，增强互动性。第三方 API 主要包含关联数据库和部分 ZXDoc 动作执行：例如**启动测量、普通发送、接收回调、激活某个仿真 message、修改获取 DBC 信号值、调用 UDS 诊断、读写标定信号等，功能同扩展脚本类似**。
