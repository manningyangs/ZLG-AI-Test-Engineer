# ADR-0001：技术栈与仓库目录结构

**状态：** Accepted（2026-11-18 人工批准，随 ARCH-01/PLAT 任务组生效）
**日期：** 2026-11-18
**依据：** 《Trae 可执行开发任务书 V1.0》第 2 章；两轮仓库盘点（docs/tasks/repo_baseline.md）

---

## 背景

仓库当前为纯文档状态（4 次本地提交，零业务代码），无既有技术栈。P1 启动前需确定技术栈与目录结构，避免后续无理由换栈。本地已出现 ZXDoc 手册与 x64 安装包（均不入库），但 zlgcan SDK 包仍未获得。

## 决策（采纳任务书 2.1 推荐栈）

| 层 | 选型 | 本机验证（2026-11-18） |
|---|---|---|
| 桌面 UI | Python + PySide6 | Python 3.12.10 可用（≥3.11 要求） |
| 应用/领域逻辑 | Python 3.12、Pydantic v2 | pip 26.2.1 可安装 |
| Test IR | JSON + JSON Schema Draft 2020-12 | 无额外依赖 |
| 本地数据库 | SQLite + SQLAlchemy 2.x + Alembic | 标准库 SQLite 可用 |
| DBC 解析 | 优先评估 cantools，输出本项目 NetworkModel | P2 阶段评估 |
| Native Host | C++17 x64（MSVC），官方头文件到位后编译 | 待 P0-02 确认编译器环境 |
| UI/Host IPC | Windows Named Pipe + 长度前缀 JSON | Python 标准库可用 |
| 测试 | pytest（unit/contract/integration/e2e 分层） | 待首次依赖提交时安装 |
| 打包 | P1 不打包；产品化阶段评估 PyInstaller | — |
| AI Provider | OpenAI-compatible 抽象 + SecretStore（Windows Credential Manager） | 接口先行、密钥不落明文 |

## 备选方案与否决理由

- **Web 前后端（浏览器/Electron/Tauri）**：否决——任务书明确禁止未经批准改用 Web 架构；本项目需要近桌面交互与本机设备 IPC，且 Electron 引入额外运行时与攻击面。
- **ctypes 直调 DLL（Python 主进程）**：否决——架构红线，UI/AI 进程不得直接加载厂商 DLL；真实 DLL 只能由 C++ Native Host 独占加载（P3）。
- **单体脚本目录（不分层）**：否决——无法满足 domain/application/adapter/UI 职责隔离与插件契约要求。

## 目录结构

采纳任务书 2.2 建议树：

```text
docs/{architecture,api,test-ir,device,security,decisions,tasks}
schemas/test-ir/v1/
src/zlg_ai_test_engine/{app,ui,application,domain,plugins,infrastructure,resources}
native/zlgcan_host/          # P0 后才接真实 DLL
plugins/{protocol_can,parser_dbc,adapter_mock,adapter_zlgcan}
examples/{dbc,projects,test-ir}
tests/{unit,contract,integration,e2e,fixtures}
scripts/{dev,test,package}.ps1
```

分层隔离硬要求：domain 不依赖 Qt；ProtocolPlugin 不碰 DLL；Parser 不碰设备；LLMProvider 不执行工具动作；UI 不判定 ECU 结果。

## 后果

- P1 起按此结构建仓；任何技术栈变更须新增 ADR（原因/替代项/风险/迁移成本/对契约影响）。
- .gitignore 已加固（f3ff97e）：厂商二进制（vendor_sdk_local/、ZXDoc_um.pdf、ZXDoc_*.zip、*.dll、*.lib、kerneldlls/）、Python 缓存/虚拟环境、IDE 目录。
- 厂商二进制永不入库；ZXDoc 手册/安装包仅本地留存作 P0 证据。
- 网络约束：git push 依赖 127.0.0.1:7897 代理，不稳定时提交留本地。

## 待确认

- PySide6 版本锁定与 LGPL 许可（运行时动态链接）在首次依赖提交时记录。
- 推送代理稳定性——当前 origin 落后本地 2 个提交。
